## 🚀 How to Navigate

Each weekly folder contains the specific source files (e.g., `.c`, `.py`) related to that week's lectures and problem sets.

- **Source Code:** Files like `hello.c` contain the actual code.
- **Executables:** Compiled binary files (like `hello.exe`) are generated locally to run the programs but are intentionally kept out of version control using a `.gitignore` file to keep the repository clean.
